# Wazuh Plugins Documentation

Documentation for the Wazuh Plugins Build System — a unified, multi-architecture
pipeline that compiles, packages, and distributes security tools (Suricata IDS,
YARA, repackaged Wazuh agents) for Wazuh deployments. This documentation is for
contributors and maintainers of the build system.
